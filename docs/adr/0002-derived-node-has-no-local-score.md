# A derived node carries no local score

The mandatory premise-only rule is superseded by [ADR 0003: Claims require a belief source](0003-belief-sources.md). Derived nodes may inherit belief or carry an additional local inference prior. The former prohibition and mandatory candidate priors are no longer the score contract. Input/output naming is defined in [ADR 0004](0004-local-input-computed-belief-override.md).
